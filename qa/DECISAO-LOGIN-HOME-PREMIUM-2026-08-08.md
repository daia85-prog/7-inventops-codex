# Decisão inicial · Login e Home

Data: 2026-08-08

Contexto:

- baseline segura congelada: `baseline-segura-2026-08-08`
- baseline atual publicada: `https://7-inventops-codex.pages.dev`
- candidata premium home: `https://velox-demo.pages.dev/inventops79/`
- candidata premium login: `https://velox-demo.pages.dev/inventops79/login-icones/`

## 1. Login

### Baseline atual

Pontos fortes:

- já está integrada à linha atual do produto;
- mantém entrada corporativa clara;
- já conversa com Microsoft 365;
- já está próxima do fluxo real do P7.

Pontos fracos:

- comunica menos valor premium logo na primeira dobra;
- branding ainda passa mais “protótipo funcional” do que “produto mundial”;
- a narrativa visual ainda não gera o mesmo impacto do protótipo premium.

### Login-ícones

Pontos fortes:

- primeira impressão muito mais forte;
- cara de produto enterprise mais madura;
- identidade mais memorável;
- melhor material para diretoria e demonstração.

Pontos de atenção:

- não pode entrar só como imagem bonita;
- precisa preservar acessibilidade, PT/ES/EN e continuidade com M365;
- precisa encaixar na base funcional atual sem quebrar o fluxo.

### Decisão

Decisão para o Login:

- **seguir com a direção visual do `login-icones`**
- **preservar da baseline atual**:
  - entrada corporativa;
  - lógica de acesso demonstrativo;
  - botão Microsoft 365;
  - texto executivo sem promessas falsas.

### Veredito

- baseline atual = base funcional
- `login-icones` = direção visual vencedora
- estratégia final = **mesclar**

---

## 2. Home

### Baseline atual

Pontos fortes:

- está conectada à navegação do produto atual;
- já aponta para módulos reais;
- é simples de consolidar no P7.

Pontos fracos:

- ainda não entrega o mesmo brilho de produto premium;
- a narrativa executiva é correta, mas menos memorável;
- falta mais presença visual para “vender” o InventOps em poucos segundos.

### inventops79

Pontos fortes:

- narrativa muito mais forte;
- posicionamento mais marcante;
- sensação de plataforma premium imediatamente maior;
- melhor ponto de partida para a “cara oficial” do produto.

Pontos de atenção:

- precisamos garantir que a estética não se desconecte do fluxo real;
- não pode virar apenas landing bonita sem continuidade operacional;
- acessibilidade deve ser revalidada ao consolidar.

### Decisão

Decisão para a Home:

- **seguir com a direção visual e narrativa do `inventops79`**
- **preservar da baseline atual**:
  - conexão direta com os módulos reais;
  - clareza sobre a proposta operacional;
  - continuidade da jornada do usuário.

### Veredito

- baseline atual = espinha funcional
- `inventops79` = direção visual vencedora
- estratégia final = **mesclar**

---

## 3. Regra para a próxima consolidação

Para Login e Home, a regra aprovada passa a ser:

1. usar a candidata premium como direção visual;
2. usar a baseline como proteção funcional;
3. consolidar só a versão combinada, nunca trocar “no escuro”.

## 4. Próximo passo recomendado

Ordem sugerida de consolidação:

1. Login premium consolidado
2. Home premium consolidada
3. Revisão conjunta das duas telas
4. Só então avançar para a próxima tela da jornada

## 5. Conclusão honesta

O melhor caminho hoje não é escolher “uma ou outra”.

O melhor caminho é:

- **pegar o impacto do premium**
- **preservar a segurança do que já funciona**
- **construir uma terceira versão melhor do que as duas**

Essa passa a ser a direção oficial para Login e Home.
